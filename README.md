## What I actually do

**Full-stack product engineering.** I build applications across the stack using Angular, React, Next.js, Node.js and NestJS, backed by PostgreSQL, MySQL and other data stores. My work has included multi-tenant SaaS platforms, healthcare systems, telecom software, e-commerce and products serving 400K+ users.

**AI-enabled applications.** My recent work combines traditional software engineering with AI/ML — from deterministic verification and classical ML/NLP to LLM-based reasoning, RAG and AI application development. My AI/ML capstone is an attempt-aware mathematics tutor that evaluates not only whether an answer is correct, but how the student reached it.

**Backend, data & integrations.** I design REST APIs, database schemas and integration layers connecting applications with external systems. I've worked with PostgreSQL, MySQL, AWS services, OAuth, NetSuite, Shopify, Stripe and other third-party APIs.

**Cloud & production delivery.** I've taken software beyond localhost: AWS infrastructure, Docker, CI/CD, Linux servers, SSL, deployments, production troubleshooting, upgrades and ongoing maintenance.
